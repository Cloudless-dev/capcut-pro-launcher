# CapCut Launcher

Лаунчер для CapCut: профили, вход по почте, выбор региона и управление проектами.
Интерфейс на русском и английском.

- [Скачать для Windows](https://github.com/Cloudless-dev/capcut-pro-launcher/releases/tag/windows-v0.054)
- [Скачать для macOS](https://github.com/Cloudless-dev/capcut-pro-launcher/releases/tag/macos-v0.054) — Apple Silicon, macOS 14+.

## Запуск

Сначала установите официальный CapCut.

**Windows:** скачайте EXE-установщик и установите лаунчер. Для запуска без установки распакуйте ZIP и откройте `CapCut Launcher.exe`.

**macOS:** откройте DMG и перенесите приложение в «Программы». [Первый запуск](macos/README.md).

Добавьте профиль, выберите регион и нажмите «Запустить CapCut».

## English

A CapCut launcher with profiles, email sign-in, region selection and project management.

[Windows](https://github.com/Cloudless-dev/capcut-pro-launcher/releases/tag/windows-v0.054) · [macOS](https://github.com/Cloudless-dev/capcut-pro-launcher/releases/tag/macos-v0.054)

Install CapCut first. On Windows, download and run the EXE installer. If you choose the ZIP,
extract it and open `CapCut Launcher.exe`. On Mac, open the DMG and move the app
to Applications. Add a profile, choose a region and click Launch CapCut.
