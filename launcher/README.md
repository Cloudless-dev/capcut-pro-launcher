# Переносимый лаунчер

Готовый комплект: `../Лаунчер/CapCut Launcher-0.02/` и ZIP рядом. В 0.02 добавлены имя сохранённого аккаунта, отслеживание закрытия окна входа, полная очистка браузерного профиля и оформленная встроенная инструкция; TXT остаётся. 0.01 обозначает первую сборку. Старые технические имена архивов 1.0.0/1.1.0 оставлены для истории.

Единый источник версии — `Version.cs`: номер отображается в главном окне и инструкции, а сборщик использует его для имени папки, ZIP и метаданных. Windows FileVersion для 0.02 равен 0.2.0.0, отображаемый ProductVersion — 0.02. Механизм сетевых обновлений пока не реализован.
Исходник интерфейса — `Launcher.cs`, иконки — `../assets/`.

Сборка: `../packaging/build_portable.py`. Она копирует только перечисленные исходники и библиотеки, не копирует пользовательский local/ целиком. Нужны заранее загруженные официальные Python embeddable, SDK/установщик WebView2 и локальная Frida. Ссылки и хеши включаются в build-info.json.

Комплект не зависит от установленного Codex/Python. Python 3.13.16 x64 и Frida 17.24.3 включены; браузерный помощник уже собран. При отсутствии WebView2 есть подписанный Microsoft bootstrapper, запускаемый только после согласия пользователя. HKCU используется без повышения прав, PowerShell Bypass действует только в дочернем процессе.

По умолчанию CapCut ищется в стандартных каталогах и зарегистрированных путях. Кнопки «Найти CapCut» и «Обзор» позволяют повторить поиск или заменить путь. Список регионов закрытый: US/NL. Настройки сохраняются в `%LOCALAPPDATA%/CapCutLauncher/settings.json`, сеанс и браузерный профиль — там же. Старые исследовательские данные не используются.

Проверенная машина: Windows 11 Pro 25H2 26200.9711 x64, CapCut FileVersion 9.6.0.4097 (ProductVersion 9.6.0.89fd5606). Чистая виртуальная машина и другие версии клиента не проверялись. В исходном проекте подтверждён сквозной вход и повторный US-запуск; сборка проверена на загрузку встроенных зависимостей и работу интерфейса. Живой вход в отдельном профиле сборки требует отдельного теста.
