# CapCut Launcher для macOS

[Скачать DMG](https://github.com/Cloudless-dev/capcut-pro-launcher/releases/tag/macos-v0.052)

Требуется macOS 14+, Apple Silicon (M-серия) и официальный CapCut с сайта производителя. Intel пока не поддерживается. Устанавливать Chrome, Python или Xcode для запуска не нужно.

## Использование

1. Перенесите приложение из DMG в «Программы».
2. Создайте профиль: укажите почту и пароль или выберите «Текущий аккаунт CapCut» для входа через официальное приложение, например через Google.
3. Выберите US / TR / NL или введите другой двухбуквенный код страны.
4. Запустите CapCut. Для смены профиля сначала закройте CapCut. Новый регион применяется при следующем запуске.

### Первое открытие

Если macOS блокирует запуск, сначала попробуйте открыть лаунчер, затем перейдите в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтвердите запуск. Кнопка появляется после попытки открыть приложение.

До запуска CapCut включите **Конфиденциальность и безопасность → Управление приложениями → CapCut Launcher**. Если лаунчера нет в списке, добавьте его кнопкой **+** из «Программ». После выдачи разрешения полностью закройте CapCut и лаунчер и откройте их снова.

В DMG есть **Installation.pdf** с иллюстрированной инструкцией на русском и английском. Она также доступна в разделе «Инструкция» лаунчера.

Вход выполняется в фоне через комплектный браузер. После проверки сервером появится «Вход подтверждён», и кнопка запуска станет доступна. Если CapCut потребует подтверждение, откроется окно входа. Для Google, Apple и других способов входа выберите «Текущий аккаунт CapCut» и войдите в официальном приложении.

При истечении сессии лаунчер повторит вход по сохранённым данным. Если CapCut открыт, восстановление начнётся после его закрытия. При ошибке входа отредактируйте профиль или войдите через браузер. Кнопки проверки сессии, редактирования и удаления находятся рядом с профилем. Регион можно выбрать прямо в карточке или в окне редактирования профиля.

В настройках: язык «Системный / Русский / English», тема «Системная / Светлая / Серая / Тёмная», размер интерфейса «Маленький / Средний / Большой», автообновления и запуск CapCut после авторизации. По умолчанию язык и тема соответствуют macOS.

Профили с почтой и паролем сохраняют отдельные браузерные сеансы в Keychain этого Mac. Профили «Текущий аккаунт CapCut» используют общий вход официального приложения. Локальные проекты общие; удаление профиля их не удаляет.

Регион не меняет IP и язык CapCut. Для платных функций нужна действующая подписка.

## Проекты

Раздел «Проекты» показывает названия и обложки. «Экспорт» сохраняет выбранные проекты (или все, если ничего не выделено) в отдельную папку. «Импорт» принимает папку экспорта или отдельного проекта; дубликаты пропускаются. Можно перенести проекты и отправить выбранные или все в корзину лаунчера. Во вкладке «Корзина» доступны обложки, даты удаления и восстановление проектов вместе с записью в списке CapCut. Автоматической очистки нет; ручная очистка перемещает их в системную Корзину macOS. Для операций закройте CapCut. При экспорте доступны два режима: «Только проект» и «Со всеми материалами». Второй собирает исходники и локальные ресурсы в папку проекта; при импорте пути обновляются автоматически. Если исходные материалы отсутствуют, полная копия не создаётся — сначала восстановите файлы либо выберите «Только проект».

## Данные

- Настройки и браузерные профили: `~/Library/Application Support/CapCut Launcher/`.
- Входы: Keychain macOS.
- Стандартный путь проектов: `~/Movies/CapCut/User Data/Projects/com.lveditor.draft`.

## Сборка

Из корня репозитория, на Apple Silicon с Command Line Tools и Python 3.14:

```sh
python3.14 -m venv .venv
.venv/bin/python -m pip install -r macos/requirements-build.txt
.venv/bin/python macos/scripts/fetch_dependencies.py
.venv/bin/python macos/packaging/build.py --dmg
```

Результат — в `releases/`. Для релизной сборки используются переменные `CODE_SIGN_IDENTITY`, `UPDATE_FEED_URL` и при необходимости `SPARKLE_PUBLIC_KEY`. Канал Mac: `macos/appcast.xml`.

Исходники — в `macos/`. Локальные тесты, исследования, учётные данные и готовые бинарники исключены из Git.
