Getting started
1. Install CapCut. If you have never opened it, launch it once, wait for its
   home screen, then close it completely so its initial files are created.
2. Extract the entire ZIP into a writable folder, such as Documents.
   Do not run it from inside the ZIP or move the EXE on its own.
3. Open CapCut Launcher.exe. Administrator access is usually not required.
4. CapCut is detected automatically. Find CapCut repeats the search.
   If needed, use Browse to select CapCut.exe from your installed version.
5. Choose a region: US — United States or NL — Netherlands.
6. For your first sign-in, choose Sign in with email, then Continue with email
   on the CapCut website. Enter your credentials yourself. Once the service
   verifies your session, the desktop app will open.
7. For later launches, use Launch CapCut in the launcher. The ordinary CapCut
   shortcut does not load the session helper.
8. Use Русский / English in the main window to switch languages.
   Your choice is saved. Help opens in the selected language.

Features
— Pro catalog visibility and region selection (US/NL).
— Region settings applied to the local cache, registry and DeviceRegister,
  with registry region values maintained while the app is running.
— Email sign-in using the official CapCut website and server-verified sessions.
— Included runtime components; a separate Python installation is not required.
— Included official Microsoft WebView2 installer, offered if WebView2 is missing.
  An internet connection is required for installation and sign-in.

Subscription
Showing Pro content does not provide a subscription. Paid features and exports
require valid access from CapCut. Subscription and export responses are not
modified. Changing the local region does not change your account country or IP.

Saved sign-in
Settings, the separate sign-in browser profile and the Windows DPAPI-encrypted
session are stored in %LOCALAPPDATA%\CapCutLauncher, outside the app folder.
The ZIP contains no personal accounts, cookies, passwords or diagnostic logs.
Sessions are tied to the current Windows user and cannot be transferred to
another PC by copying files. Each user signs in to their own account.

If CapCut automatically resets sign-in, the saved copy is retained and checked
with the server on the next launch. If it expires or is revoked, sign in again.
After signing in, the button shows the email or account name returned by CapCut.
For older sessions, the available native profile name is used. This is the
saved account; session validity is verified when the desktop app starts.

Forget sign-in removes the saved session, the launcher's entire browser profile
(including cookies), and the local CapCut account entry. Close both CapCut and
the sign-in window first. The next sign-in window starts without the previous
account. Projects and your regular Chrome/Edge profiles are not affected.
Signing out only inside CapCut does not erase the launcher's saved sign-in;
the next launch may restore it. Closing the sign-in window updates the status;
cancelling it is not treated as a successful sign-in.

Help opens inside the launcher. Both English and Russian text files are also
included for reading without running the application.

Troubleshooting
PowerShell and permissions
The launcher uses -ExecutionPolicy Bypass only for its child PowerShell process.
No manual Set-ExecutionPolicy command is required. It does not change system
execution policies, security settings or file permissions. Settings are written
under HKCU\Software\Bytedance\CapCut and the current user's files; administrator
access is usually unnecessary. HKLM is not modified. WebView2 installation
uses Microsoft's installer after your confirmation.
The launcher is not signed with a commercial publisher certificate. Windows
may report an unknown publisher; verify the origin and contents of the ZIP.
If an organization's Group Policy or AppLocker blocks PowerShell, its
administrator must allow it. The launcher does not bypass those restrictions.

Common issues
— Close CapCut and the sign-in window completely, then try again.
— Choose Check setup and verify the selected CapCut.exe.
— Unexpected cache format: open CapCut normally once, then close it.
  If the issue remains, that CapCut version may require adaptation.
— WebView2 installation needs access to Microsoft servers.
— If the server rejects your session, sign in again with email.

Version history: 0.01 — first build; 0.02 — saved account display, full browser

Updates
Click the version in the upper-right corner. When an update is available,
the launcher offers to download it and restarts after installation.
Close CapCut and the sign-in window first. Account data is retained.
The previous folder is kept with a .backup suffix; you may remove it later.
